# m13 · Внутренняя алхимия

MVP онлайн-школы реальной культивации (нэй дан) для аудитории дунхуа.

## Стек

- Vue 3 + TypeScript + Vite
- Vue Router
- SCSS

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`

## Страницы MVP

| Путь | Описание |
|------|----------|
| `/` | Лендинг: бренд, тезисы, пруфы, этапы, оффер |
| `/path` | Структура знаний + инфографики |
| `/cabinet` | Личный кабинет: видео + текст обучения |

## Дизайн

Тёмная «тушь», киноварь (赤符), золото, нефрит. Шрифты: Cormorant Garamond + Outfit + Noto Sans SC.
